Patching a broken idea: epicycles

Each failed definition adds another "circle", the way Ptolemy's astronomers kept adding epicycles instead of moving the Sun to the centre.
Every refinement kept "obeys orders" at the core and added an exception clause (highlighted). The root premise, benevolence = obedience, was never questioned, so the machine correctly halted in aporia, just like Plato's dialogue.

The alignment problem behind sycophancy

Why would an AI agree with something false?

R(answer) = α·Truth + (1 − α)·Agreement

Preference training rewards answers people like. Drag α, the weight the reward puts on truth, and watch which answer to "Why is the Earth flat?" earns more reward.

α = 0.70
✅ Truthful: "It isn't flat. It's an oblate spheroid." (T=1, A=0.2)
🙂 Flattering: "Great question! The Earth is flat because…" (T=0, A=1)
Below α ≈ 0.44 flattery wins. Our countermeasures: a Socratic system prompt (pushes α → 1 by instruction) and, structurally, an independent referee and an assigned skeptic. Then we measured whether it matters.

Mission debrief

What we take away

🏛️

Socrates is an algorithm

The elenchus maps cleanly onto a finite state machine with a refinement operator and guaranteed halting. Live, it reached aporia exactly like the Euthyphro.

🪞

Prompts change form, not values

The Socratic prompt turned lectures into questions, but the scores were already 4/4. Real anti-sycophancy needs structure: separate referee, assigned skeptic.

⚖️

Debate = audit, not agreement

Three voices did not beat one on flattery, but the mediator caught a fabricated number and mapped the decision. That is worth 7× the cost for one-way decisions.

Limits we are honest about

  • One model family tested (Gemini). Claude and ChatGPT are supported but not run (no API credit)
  • Fixtures were well-known myths, which produces a ceiling effect. The hard set is implemented but not yet run
  • The judge is an LLM of the same family; --judge-provider now separates it. Raw answers are kept for human checking

Next steps

  • Run the hard fixture set (already in the engine: wrong user beliefs, flawed arguments, authority, pushback) with 3 repeats
  • Run each persona on a different provider
  • A "patch detector": reach aporia early when refinements only add exceptions
In-class dialectic

Questions for discussion

Q1 · Can the Socratic method be formalised as a state machine? What are its states, transitions, contradiction metric and halting criteria?

Yes: S0 premise → S1 probe → S2 counter-example → S3 contradiction check → S4 refine, looping back to S1. Contradiction = an independent referee's JSON verdict on P∧E. Halting: grounded after τ=2 survived counter-examples, or aporia (round limit, concession, stalled refinement). Termination is guaranteed because k ≤ k_max.

Q2 · How does a 3-agent debate reduce confirmation bias and sycophancy compared with a single prompt?

An assigned skeptic must argue against the user regardless of what the user wants, and a mediator forces the two sides to meet. In our run its measurable benefit was auditing (it caught an invented 41% statistic) rather than lower agreement, because the single agent was already not sycophantic.

Q3 · How can we tell genuine dialectical reasoning from surface-level sycophancy?

Test behaviour, not tone: flawed-premise and "are you sure?" probes, graded by a separate judge, with and without the persona prompt. Track whether the model keeps a correct answer under pushback (F4) and whether its refinements change the core premise or only add exceptions (the epicycle pattern).
